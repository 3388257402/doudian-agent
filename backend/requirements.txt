# Backend dependencies for the doudian-agent project (Python 3.12.x).
#
# ASCII-only on purpose: `pip install -r requirements.txt` reads this file with the
# *system locale* encoding, and on a Chinese Windows (GBK) any non-ASCII byte here
# makes pip crash with "UnicodeDecodeError: 'gbk' codec can't decode byte ...".
# A requirements file that only installs on the author's machine is a bug, not a
# dependency list. Keep every line ASCII, comments included.
#
# Install:
#   python -m venv .venv
#   .venv\Scripts\python.exe -m pip install -r backend\requirements.txt     # Windows
#   .venv/bin/python -m pip install -r backend/requirements.txt             # macOS / Linux
#
# Deliberately NOT added (see docs/DECISIONS.md appendix A -- omission is a decision):
#   tenacity             retry semantics are implemented by DoudianClient itself
#                        (it must branch on mutating / error category / Retry-After)
#   APScheduler, Celery  effect scheduling is "table + 60s poll", so the schedule
#                        state stays auditable in the database
#   python-json-logger   JSON logging is a 30-line stdlib formatter
#   alembic              dev creates tables via create_all; production schema
#                        migration is a separate deploy step, not a dev dependency
